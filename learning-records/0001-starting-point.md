# Starting point: strong front end, no back end

Jay is fluent in JavaScript, TypeScript, React and Vue, and has basic SQL. He has not built a Node backend, written auth, done RBAC, used Docker, or deployed anything.

Teach server-side concepts from scratch, but never re-explain TypeScript, async/await, npm, or component thinking. Lean on his front-end intuition as the bridge — e.g. introduce middleware as "a function that runs before your handler", and RBAC as "the check the hidden button was only pretending to do".

Evidence: stated directly during the grilling session on 2026-09-01.
